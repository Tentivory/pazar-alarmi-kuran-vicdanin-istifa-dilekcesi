# Pazar Günü Alarm Kuran Vicdanın İstifa Dilekçesi

Bu yazılım, Pazar günü alarm kuran iç sesin T.C. İç Ses İnsan Kaynakları Dairesi'ne sunduğu resmi istifa dilekçesini üretir.

**Ciddiyet katsayısı:** 11/10  
**Komiklik katsayısı:** Resmen yok (yalan)  
**Patates:** Yok. Yasak. Konu dışı.

## Neden var?

Çünkü vicdan fazla mesai yapıyor. Pazar günü 07:30'da çalan alarm, yastık sendikasının grev hakkını ihlal eder. Bu durum bilimsel olarak kanıtlanmamıştır ama evrak çok resmi durduğu için doğrudur.

## Kurulum

```bash
python3 vicdan.py
```

Çıktıyı yastığın altına koyunuz. Alarm itiraz ederse rüyada duruşma açılır.

## Kullanım Örneği

Program her çalıştırıldığında yeni bir gerekçe ve talep seçer. Örnek talepler:

- istifanın kabulü
- üç Pazar izin
- alarmın sürgünü
- yastığa resmi özür
